# InfraGridX - Enterprise IT Infrastructure Solutions

## Overview
InfraGridX is a comprehensive enterprise IT infrastructure solutions provider offering cloud services, data center solutions, cybersecurity, and DevOps services.

## Features
- 🏢 Data Center Infrastructure & Services
- ☁️ Cloud Services (AWS, Azure, GCP, Oracle)
- 🔒 Cybersecurity Solutions
- 🖥️ Managed Servers
- 🚀 DevOps Services
- 🤝 Partner Program
- 📊 RIMS, NOC, SOC Services

## Tech Stack
- Django 5.0
- PostgreSQL
- Bootstrap 5
- Gunicorn
- Nginx

## Deployment
This project is deployed using Git with CI/CD pipeline.
